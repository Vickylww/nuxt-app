## 优化前的困境

- 首屏加载超过 4 秒
- 动态内容依赖客户端 API 调用
- 图片未压缩，阻塞渲染

## 优化策略一览

1. **SSR + ISR**：所有首屏关键内容在服务端渲染，并启用增量静态再生。
2. **图片优化**：使用 Nuxt Image 模块自动转换 WebP，响应式加载。
3. **字体优化**：`font-display: swap` 确保文字快速可见。
4. **代码分割**：路由懒加载，减少初始包体积。

### 最终成果

- LCP 降低 **55%**
- TBT（总阻塞时间）减少 **70%**
- 移动端评分从 62 提升至 98

这些优化让官网在搜索引擎中的排名明显提升，用户跳出率下降 40%。
