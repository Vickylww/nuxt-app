##项目结构

```
nuxt-app/
├── articles/                # Markdown 文章
├── assets/               # 需要构建工具处理的资源
├── components/           # 公共组件
├── composables/          # 组合式函数
├── layouts/              # 布局
├── pages/                # 页面路由
├── public/               # 静态资源
├── server/               # 服务端逻辑
│   ├── api/              # CMS 等接口
├── utils/                # 工具函数
├── nuxt.config.ts        # Nuxt 配置文件
└── package.json

```
